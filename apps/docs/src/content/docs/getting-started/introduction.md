**Status: scaffold (ADR-0011).** morpha is a Presentation Domain Engine — a
framework-agnostic core for visual documents, built as a pnpm monorepo and
governed by the Architecture Handbook.

This section will host installation, first-document, and orientation guides
once the packages they describe exist. Until then, read the handbook
(Architecture section) and explore `apps/playground`.
