# tests/e2e/

**Deliberately empty (deferred).** Playwright-based end-to-end tests arrive
with the first browser-facing app — either `apps/playground` reaching
interactive maturity or `examples/04-basic-editor` becoming runnable.

Per [ADR-0011](../../docs/architecture/adr/ADR-0011-development-applications-workspace.md),
this is DP7 applied to its actual target — a genuinely speculative test
harness with no consumer yet — not a blanket "no scaffolds" rule.
